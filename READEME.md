\# Smart Expense Tracker 💰



A web-based expense management application developed using \*\*Core Java, HTML, CSS, and JavaScript\*\*. It helps users track their income and expenses, view financial summaries, and generate reports through a clean dashboard.



\## 🚀 Features



\- Add and manage income and expenses.

\- View total income, expenses, and balance.

\- Display transactions in a dashboard table.

\- Visualize monthly financial activity.

\- View expense categories using charts.

\- Generate financial reports.

\- Store transaction data locally using file handling.

\- Responsive and user-friendly interface.

\## ⚙️ How to Run the Project



\### Prerequisites

\- Java Development Kit (JDK 21 or later)

\- Git



\### Steps



1\. Clone the repository:



```bash

git clone https://github.com/anjali83094-lab/Smart-Expense-Tracker.git

```



2\. Navigate to the project directory:



```bash

cd Smart-Expense-Tracker

```



3\. Compile the Java source files:



```bash

javac -d out src/\*.java

```



4\. Start the application:



```bash

java -cp out Main

```



5\. Open your browser and visit:



```text

http://localhost:8080

```
